Legal Document Category Prediction Using Machine Learning

An intelligent NLP system that parses legal agreements, deeds, and court judgments in PDF or TXT formats, extracts discriminative linguistic features, and automatically classifies them into domain-specific categories with calibrated confidence scores and feature interpretations.

Core Capabilities & Technical Highlights

Demonstrating modern Natural Language Processing and Supervised Learning pipelines.

PyMuPDF Document Ingestion

High-speed local PDF and TXT text extraction without external APIs. Accurately flags non-selectable or scanned image-only documents.

Legal Domain NLP Pipeline

TF-IDF unigram & bigram vectorization with custom tokenizers that preserve critical legal modal verbs, negations, and covenants.

Tri-Algorithm Benchmarking

Trains and evaluates Multinomial Naive Bayes, Logistic Regression, and Calibrated Linear SVM using Stratified K-Fold Cross-Validation.

Explainable Feature Attribution

Inspects classifier weights and log-odds coefficients to extract the top indicative lexical terms that triggered the document's classification.

K-Means & TruncatedSVD

Interactive unsupervised document clustering and 2D sparse vector dimensionality reduction for exploratory corpus analysis.

Automated Report Generation

Exports formal academic classification reports and model evaluation summaries in PDF and plain text format via ReportLab.

End-to-End Machine Learning Workflow Pipeline

1
Ingestion & Extraction

Upload PDF/TXT or paste text. PyMuPDF extracts text streams and validates length & encoding.

2
NLP Preprocessing

Lowercasing, punctuation normalization, domain stopword filtering, and sublinear TF-IDF vectorization.

3
Model Classification

Evaluates candidate classifiers and executes inference using the persisted best pipeline.

4
Diagnostics & Audit

Outputs calibrated confidence, ranks top indicative terms, logs snippet to SQLite, and generates PDF report.
