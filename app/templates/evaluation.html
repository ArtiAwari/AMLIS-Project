Why Macro F1-Score? Macro F1 calculates metrics independently for each legal category and averages them unweighted. This treats low-frequency contract types with equal importance, preventing majority classes from dominating evaluation.
Evaluation Methodology & Academic Scope
1. Data Leakage Prevention

The TF-IDF feature vocabulary and IDF weight vector are strictly fitted only on the training partition. The unseen test set is transformed using the fitted vocabulary, guaranteeing zero test data contamination.

2. Calibrated Decision Scores

Support Vector Machines natively output uncalibrated signed functional margins. LinearSVC is wrapped in CalibratedClassifierCV using sigmoid Platt scaling to produce valid posterior probability estimates.

3. Dataset Limitations & Future Scope

High accuracy on sample datasets reflects distinct boilerplate legal phrasing. In real-world enterprise legal systems, multi-label contracts (e.g. lease + NDA clauses combined) require multi-label architectures or LegalBERT transformers.
